# Grow Your Money — Migración Astro

Landing migrada desde `index.html` a componentes Astro, manteniendo estilos y comportamiento originales.

## Comandos

```bash
npm install
npm run dev
npm run build
```

El HTML original incluía una referencia a `icono.png`, pero ese recurso no fue entregado junto con la maqueta. La ruta `/icono.png` queda preparada para incorporarlo en `public/` sin cambiar el código de la landing.
